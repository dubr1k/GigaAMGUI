Загрузка файлов

⇪ Выберите аудио или видео .wav, .mp3, .m4a, .mp4, .mov, .mkv

Прямая ссылка на файл. Также можно попробовать публичные записи YouTube, Reddit, TikTok, Instagram и X, но загрузка с этих площадок не гарантируется. Плейлисты и эфиры не поддерживаются. До 2 ГиБ на файл.

Настройки обработки

WeSpeaker: дополнительная модель загружается при необходимости.

Экспериментально, только Windows и Linux; качество разделения говорящих может быть нестабильным. При первой обработке с выбранной Community-1 закреплённая версия модели FP32 загружается автоматически — требуется интернет.

Возможное наложение помечается [SPEAKER_OVERLAP]: участники не перечисляются, отдельные голоса и тексты не восстанавливаются.

Расположение и ручная подготовка пакета

Вместо автоматической загрузки можно использовать локально подготовленный экспорт закреплённого снимка 3533c8cf8e369892e6b79ff1bf80f7b0286a54ee, созданный скриптом packaging/rust-liquid/community-export/export.py из исходного репозитория.

Для ручной установки поместите export.json, plda.json, tract/segmentation.onnx и tract/embedding.onnx в models/pyannote-community внутри папки данных приложения.

Для Rust Liquid папка данных: Windows — %APPDATA%\ru.gigaam.gui.rustliquid; Linux — $XDG_DATA_HOME/ru.gigaam.gui.rustliquid (обычно ~/.local/share/ru.gigaam.gui.rustliquid).
