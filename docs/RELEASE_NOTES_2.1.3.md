# GigaAM Transcriber 2.1.3

Исправление вёрстки PyQt-интерфейса по issue #54 и новая иконка GigaAMLiquid.

## Исправлено

- **Заголовки карточек на странице «Обработка».** С редизайна 2.0 под
  заголовок `QGroupBox` было отведено 8 px при высоте строки 14 px, и фон
  рамки закрашивал нижнюю половину текста («Режим», «Диаризация», «Форматы
  вывода», «Добавление файла», «Папка сохранения»). В тёмной теме заголовки
  оставались тёмно-серыми, а подписи вроде «Выбранные файлы» получали
  непрозрачные полосы. Теперь заголовок целиком над рамкой, тёмная тема
  перекрашивает его и держит подписи прозрачными.
- **Пустые «коробки» в колонке настроек.** Свободная высота делилась поровну
  между заголовком и карточками; теперь уходит в stretch, карточки компактные.
- **Мелкий шрифт на Windows.** Масштаб UI считался от базовых 12 pt, поэтому
  Segoe UI 9 pt давал 0.75 (зажим до 0.85), а macOS с 13 pt — 1.08. База
  теперь платформенная: Windows 1.06, macOS 1.08, Linux 1.05.
  `GIGAAM_UI_SCALE` по-прежнему умножает результат.
- **Поле «Символов»** для субтитров больше не скрывается в узком окне: обе пары
  «подпись + счётчик» лежат на сетке и помещаются в колонку.
- **GigaAMLiquid, Live → «Параметры».** Подписи «Диаризация (.txt)» и
  «Диар. + таймкоды» обрезались до «Диаризация» / «Диар. +» в половине
  карточки; теперь каждая на своей строке, как на странице «Обработка».

Спасибо @eXpressionist за скриншоты и вывод диагностики, по которым баг
воспроизвёлся офскрин на macOS один в один.

## Изменено

- **Иконка GigaAMLiquid.** Фирменный знак из сайдбара (три звуковые полосы) на
  скруглённой плашке в стиле macOS 26. Генерируется
  `scripts/make_liquid_icon.py`; PyQt-сборки остаются с прежней иконкой.

## Проверено

- `tests/test_gui_issue_54_layout.py` — восемь регрессионных тестов: заголовок
  не пересекает рамку (`QStyle.subControlRect`), карточки не растянуты сверх
  `sizeHint`, тёмная тема перекрашивает заголовки, платформенный шрифт по
  умолчанию даёт масштаб ≈ 1, поле «Символов» видно и внутри колонки. Все
  падают на 2.1.2 и проходят на 2.1.3.
- Офскрин-рендер страницы «Обработка» при 9 pt и 13 pt в обеих темах.
- pytest, ruff, `swift build -c release` без предупреждений.

## Packaging

- Версии PyQt, AppKit, Tauri, npm и Cargo синхронизированы на `2.1.3`.

---

Fixes the PyQt processing page layout from the 2.0 redesign (issue #54):
card titles were painted over by the frame, dark-theme titles stayed dark and
labels grew opaque bands, the settings column split spare height between cards,
the UI scale collapsed on Windows' 9 pt default font, and the subtitle
"Characters" field was hidden in compact windows. GigaAMLiquid gets its own icon
(the sidebar sound-bar mark). Thanks to @eXpressionist for the report.
