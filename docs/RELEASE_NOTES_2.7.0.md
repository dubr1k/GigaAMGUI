# GigaAM 2.7.0

## Rust Liquid для Windows и Linux

- Отдельное приложение с интерфейсом Liquid и локальным распознаванием без Python в приложении.
- Добавлены модели GigaAM v4 и Multilingual v2, потоковое распознавание и экспериментальная обработка длинных записей с диаризацией.
- Поддерживаются импорт прямых медиа-ссылок и отдельных публичных записей, экспорт и Live-захват. Доступность ссылок зависит от площадок; плейлисты и прямые эфиры не поддерживаются.
- Для системного звука Linux требуется PulseAudio или PipeWire-Pulse. Модели загружаются отдельно.

Диаризация является статистической: неопределённая и перекрывающаяся речь помечаются отдельно. Качество на длительных естественных разговорах не подтверждено синтетическим тестом.

## macOS

- Добавлены варианты GigaAM v4 и Multilingual v2 для Apple Silicon с PyTorch; MLX и Intel для этих моделей не поддерживаются.
- Сохранено исправление открытия пронумерованных результатов повторной обработки из версии 2.6.9.

Первые запуски моделей требуют загрузки данных, если они не включены в выбранный автономный комплект.
