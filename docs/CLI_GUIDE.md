# GigaAM v3 Transcriber - Руководство по CLI

Продвинутый интерактивный командный интерфейс для транскрибации аудио и видео файлов без графического интерфейса.

## Возможности CLI

✨ **Интерактивный режим** - удобные меню для выбора файлов и настроек  
🎨 **Красивый интерфейс** - цветной вывод, прогресс-бары, таблицы результатов  
⚡ **Пакетная обработка** - обработка множества файлов за один запуск  
🔧 **Гибкие опции** - работа как в интерактивном, так и в автоматическом режиме  
📊 **Детальная статистика** - таблицы результатов и времени обработки  
🖥️ **Идеально для серверов** - работает без X11/GUI

## Установка

CLI использует те же зависимости, что и GUI версия, плюс две дополнительные библиотеки:

```bash
# Активируйте окружение
source /mnt/storage10tb/anaconda/bin/activate /mnt/storage10tb/anaconda/envs/gigaam

# Установите дополнительные зависимости (если еще не установлены)
pip install questionary click

# Сделайте скрипт исполняемым
chmod +x cli.py
```

## Быстрый старт

### 1. Интерактивный режим (рекомендуется)

Самый простой способ - просто запустите CLI без аргументов:

```bash
python cli.py
```

Вам будет предложено:
1. Выбрать файлы или директорию
2. Указать папку для сохранения результатов
3. Подтвердить начало обработки

### 2. Автоматический режим

Обработать все файлы в директории:

```bash
python cli.py -d /path/to/audio/files -o /path/to/output
```

Обработать конкретные файлы:

```bash
python cli.py -f audio1.mp3 -f audio2.wav -f video.mp4 -o /path/to/output
```

## Параметры командной строки

```
Опции:
  -f, --files PATH          Путь к файлу (можно указать несколько раз)
  -d, --directory PATH      Директория с файлами для обработки
  -o, --output PATH         Директория для сохранения результатов
  -i, --interactive         Интерактивный режим (по умолчанию)
  -n, --no-interactive      Неинтерактивный режим
  -v, --verbose            Подробный вывод
  --help                   Показать справку
```

## Примеры использования

### Пример 1: Полностью интерактивный режим

```bash
python cli.py
```

**Результат:** Откроется интерактивное меню, где вы сможете выбрать файлы и настройки.

### Пример 2: Обработка директории

```bash
python cli.py -d ~/Music/podcasts
```

**Результат:** Все поддерживаемые аудио/видео файлы в директории будут обработаны, результаты сохранятся в той же директории.

### Пример 3: Указание конкретных файлов и папки вывода

```bash
python cli.py \
  -f ~/audio/interview1.mp3 \
  -f ~/audio/interview2.m4a \
  -f ~/video/conference.mp4 \
  -o ~/transcriptions
```

**Результат:** Три указанных файла будут обработаны, результаты сохранятся в `~/transcriptions`.

### Пример 4: Пакетная обработка с подробным выводом

```bash
python cli.py -d ~/recordings -o ~/output -n -v
```

**Результат:** Все файлы из `~/recordings` будут обработаны в неинтерактивном режиме с подробным логированием.

### Пример 5: Использование в скриптах

```bash
#!/bin/bash
# process_all.sh - скрипт для автоматической обработки

source /mnt/storage10tb/anaconda/bin/activate /mnt/storage10tb/anaconda/envs/gigaam

for dir in /data/recordings/*/; do
    echo "Обработка: $dir"
    python cli.py -d "$dir" -o "/data/transcriptions/$(basename "$dir")" -n \
        || echo "В $dir есть необработанные файлы (код $?)"
done
```

### Коды выхода

| Код | Когда |
|-----|-------|
| `0` | Все файлы обработаны; нет файлов для обработки; отказ на вопросе «Начать обработку?» |
| `1` | Хотя бы один файл не обработан, не загрузилась модель, нет ffmpeg или `HF_TOKEN` для pyannote |
| `2` | Неверные аргументы или файлы перезапишут одинаковые результаты |
| `130` | Прервано по Ctrl-C (в том числе на вопросе «Начать обработку?») |

> До версии с этим разделом CLI выходил с `0`, даже если не обработался ни один файл, а Ctrl-C давал `1`
> («Aborted!» от click). Скрипты, проверявшие только «не ноль», теперь видят частичный провал пакета.

## Интерактивные меню

При запуске в интерактивном режиме вы увидите следующие меню:

### 1. Выбор режима работы

```
? Как вы хотите выбрать файлы?
  📁 Выбрать директорию (обработать все файлы)
❯ 📄 Указать отдельные файлы
  ❌ Отмена
```

### 2. Выбор файлов/директории

В зависимости от выбора:
- **Директория:** введите путь к папке с файлами
- **Отдельные файлы:** добавляйте файлы по одному

### 3. Выбор папки для результатов

```
? Сохранить результаты в ту же директорию? (Y/n)
```

### 4. Подтверждение обработки

```
? Начать обработку 5 файлов? (Y/n)
```

## Форматы файлов

CLI поддерживает те же форматы, что и GUI:

**Аудио:**
- MP3, WAV, M4A, FLAC, OGG, WMA

**Видео:**
- MP4, AVI, MOV, MKV, WEBM

## Результаты обработки

Для каждого файла создаются два текстовых файла:

1. **`filename.txt`** - чистая транскрибация
   ```
   Добрый день, сегодня мы поговорим о машинном обучении.
   Эта тема очень актуальна в современном мире.
   ```

2. **`filename_timecodes.txt`** - с временными метками
   ```
   [00:00:00 - 00:00:05] Добрый день, сегодня мы поговорим о машинном обучении.
   [00:00:05 - 00:00:12] Эта тема очень актуальна в современном мире.
   ```

## Производительность

### Примерное время обработки

| Длительность | CPU (8 ядер) | GPU (CUDA) |
|--------------|--------------|------------|
| 5 минут      | ~2-3 мин     | ~1 мин     |
| 30 минут     | ~15-20 мин   | ~5-7 мин   |
| 1 час        | ~30-40 мин   | ~10-15 мин |

*Время зависит от конфигурации системы и качества аудио*

### Советы по производительности

1. **GPU ускорение:** CLI автоматически использует CUDA если доступна
2. **Пакетная обработка:** обрабатывайте много файлов за раз
3. **Фоновый режим:** используйте `nohup` для длительных задач

```bash
nohup python cli.py -d /large/dataset -o /output -n > process.log 2>&1 &
```

## Автоматизация

### Cron задача для автоматической обработки

```bash
# Добавьте в crontab (crontab -e)
0 2 * * * /path/to/process_daily.sh
```

Содержимое `process_daily.sh`:

```bash
#!/bin/bash
source /mnt/storage10tb/anaconda/bin/activate /mnt/storage10tb/anaconda/envs/gigaam
cd /mnt/storage10tb/syncthing/development/GigaAMv3

python cli.py \
  -d /data/incoming \
  -o /data/transcribed \
  -n \
  >> /var/log/transcribe.log 2>&1
```

### Watch директории

Автоматически обрабатывать новые файлы:

```bash
#!/bin/bash
# watch_and_process.sh

WATCH_DIR="/data/incoming"
OUTPUT_DIR="/data/output"

source /mnt/storage10tb/anaconda/bin/activate /mnt/storage10tb/anaconda/envs/gigaam

while inotifywait -e create -e moved_to "$WATCH_DIR"; do
    sleep 5  # Даем время на копирование
    python cli.py -d "$WATCH_DIR" -o "$OUTPUT_DIR" -n
    mv "$WATCH_DIR"/* /data/processed/  # Переместить обработанные
done
```

## Решение проблем

### CLI не запускается

```bash
# Проверьте активацию окружения
which python
# Должно показать: /mnt/storage10tb/anaconda/envs/gigaam/bin/python

# Переустановите зависимости
pip install questionary click rich
```

### Нет цветного вывода

```bash
# Убедитесь, что терминал поддерживает цвета
echo $TERM
# Должно быть: xterm-256color или screen-256color

# Для tmux добавьте в ~/.tmux.conf:
set -g default-terminal "screen-256color"
```

### Ошибка "HuggingFace токен не найден"

Убедитесь, что файл `.env` существует и содержит:

```bash
HF_TOKEN=hf_ваш_токен_здесь
```

### Медленная работа на CPU

CLI автоматически использует GPU если доступен. Проверьте:

```bash
python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}')"
```

Если `False`, убедитесь что:
1. Установлены драйверы NVIDIA
2. PyTorch установлен с CUDA: `pip list | grep torch`
