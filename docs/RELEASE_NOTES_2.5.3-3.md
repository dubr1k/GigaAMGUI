# GigaAM Transcriber 2.5.3-3

## Исправлено

- В Liquid счётчик выбранных файлов находится на одной линии с кнопкой «Очистить».
- В каждой строке списка есть крестик цвета текста: он убирает только этот файл из очереди. Во время обработки удаление недоступно.

## Проверка

Добавить в Liquid два файла, удалить один крестиком и убедиться, что второй остаётся в очереди, а счётчик обновляется. Затем нажать «Очистить».

---

## English

### Fixed

- In Liquid, the selected-file count is vertically aligned with the Clear button.
- Each file row has a text-colored remove button that removes only that file from the queue. Removal is disabled while processing.

### Verify

Add two files in Liquid, remove one with its row button, confirm the other remains and the count updates, then click Clear.
