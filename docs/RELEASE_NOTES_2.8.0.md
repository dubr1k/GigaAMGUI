# GigaAM 2.8.0

## Community-1

- В Rust Liquid для Windows и Linux добавлен экспериментальный выбор pyannote Community-1. При первом использовании приложение загружает закреплённую FP32-модель и проверяет размеры и SHA-256 файлов; существующая локальная модель не перезаписывается.
- В Python-клиенте Community-1 запускается в отдельном окружении, не заменяя существующий движок pyannote 3.1. Для установки окружения требуется совместимый CPython; автоматическая установка на Intel macOS не поддерживается.
- Доступны инструменты локального экспорта и экспериментальной ONNX INT8-квантизации. Это не автоматическая поставка INT8-модели: качество, скорость и работа INT8 в установленных приложениях на Windows/Linux не подтверждены.

Диаризация статистическая: голоса могут объединяться или разделяться ошибочно, а перекрывающаяся речь помечается отдельно без восстановления отдельных текстов. Короткие синтетические проверки не устанавливают качество на длительных естественных разговорах.
