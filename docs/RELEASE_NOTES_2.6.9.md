# GigaAM Transcriber 2.6.9

## Исправлено

- **Открытие повторных расшифровок в GigaAM Liquid.** Если результат с таким именем уже есть, воркер сохраняет новый с номером (`запись_1.txt`). Liquid теперь открывает такие файлы, включая варианты с таймкодами и метками говорящих.

## English

### Fixed

- **Opening repeated transcriptions in GigaAM Liquid.** When an output file already exists, the worker saves the new one with a numeric suffix (`recording_1.txt`). Liquid now opens these files, including timestamped and speaker-labeled variants.
